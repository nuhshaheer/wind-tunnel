**Estimate scripts** (run from the session scratchpad; outputs are quoted in [buy_list.md](../buy_list.md)). Fan top
speed with the S6 (`s6speed.py`):

```python
rho, A, CFM = 1.20, 0.01, 2118.88          # kg/m^3; 100 mm section m^2; CFM per m^3/s
def top(Qf, Pm, k, sag=1.0):               # straight-line fan curve: Qf CFM free air, Pm Pa at zero flow
    lo, hi = 0.1, 40                         # fan pressure needed = k * q in the test section (open exit)
    for _ in range(80):
        m = (lo+hi)/2
        lo, hi = (m, hi) if sag*Qf*(1 - k*0.5*rho*m*m/Pm) > A*m*CFM else (lo, m)
    return lo
for Qf in (402, 425): print(Qf, top(Qf,503,1.5), top(Qf,503,1.25), top(Qf,503,1.75))   # 13.12-13.68; 13.51-14.11
for sag in (0.9, 0.8): print(sag, top(425,503,1.5,sag), top(425,503,1.25,sag))         # 12.78-13.29; 11.95-12.38
print(143.6/402*top(402,503,1.5), 143.6/402*top(402,503,1.25))  # level 1 (old forum figure): 4.7-4.9 m/s
for Q,P in ((400,300),(425,503),(402,503)): print(Q,P,top(Q,P,1.55),top(Q,P,1.55,0.9))
# VEVOR 400/300: 11.3 (10.8); S6 425/503: 13.4 (12.7); S6 402/503: 13.0 (12.3)
```

Force balance (`balance.py`; sphere C_D from Brown and Lawler Eq. (19); sting a cylinder with C_D 1.1 assumed):

```python
rho, mu, g = 1.20, 1.81e-5, 9.80665
cd = lambda Re: (24/Re)*(1 + 0.150*Re**0.681) + 0.407/(1 + 8710/Re)
F = lambda V, d: 0.5*rho*V**2*cd(rho*V*d/mu)*3.14159265*d*d/4/g*1000          # gf
# 3/4 in: 2.85 %, 0.30 gf at 6.5 m/s, 1.27 gf at 13; 1 in: 5.07 %, 0.54 / 2.31 gf
L = 0.050 - 0.01905/2                                                          # exposed sting, m
sting = lambda V, ds: 0.5*rho*V**2*1.1*ds*L/g*1000
# 1/8 in sting at 13 m/s: 1.46 gf = 115 % of the 3/4 in ball; 2 mm: 0.92 gf = 73 %; 5 mm exposed: 0.11-0.18 gf
# TAL221 100 g: 0.05 g = 3.9 % (13 m/s) and 16.8 % (6.5 m/s) of the 3/4 in drag; 0.01 g/degC = 0.8 / 3.4 %/degC
# trend rise, 3/4 in at 6.5 m/s -> 1 in at the top: 7.8 % (11 m/s), 8.5 % (12), 9.2 % (13); force 71 %, 85 %, 100 %
```

Screens (`screens.py`, `mcm_screen.py` and inline runs; Wieghardt eq. (11), ν = 1.5×10⁻⁵ m²/s; 13 m/s test section,
7.4 m/s at the 150 mm fan outlet, 2.08 m/s in the settling chamber):

```python
nu, rho = 1.5e-5, 1.20
def k(u, d_m, beta): return 6.5*(u*d_m/(beta*nu))**(-1/3)*(1-beta)/beta**2
# beta = (1 - wire_in*mesh)^2 for square mesh; (1-0.011*18)*(1-0.011*16) = 0.661 for 18x16 insect screen
# results (K inlet / K chamber / loss of four screens):
```
